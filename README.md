# benystyper

A simple 30-second typing test built with HTML, CSS, and JavaScript.

Try it online: [benystyper](https://dennisetiadi.github.io/benystyper-cobavibecodeceunah/)

## Features

- Live WPM and final accuracy, raw WPM, and character counts
- Optional punctuation removal and lowercase modes
- History of the 10 most recent tests, saved in browser storage

## Run locally

Open `index.html` in a browser. No build step is required.

## Deploy

GitHub Actions deploys the site to GitHub Pages when changes are pushed to `master`.
